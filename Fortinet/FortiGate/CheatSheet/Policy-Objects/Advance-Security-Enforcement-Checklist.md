# 3. Local-In Policy Checklist

## Purpose

Local-In Policy controls traffic reaching FortiGate itself.

Example traffic:

```
Client
 |
 |
 v
FortiGate Interface
 |
 |
 v
FortiGate Service
```

Supported services:

* SSH
* HTTPS
* Ping
* SNMP
* IPsec
* BGP
* OSPF

---

# Local-In Configuration Checklist

Example:

```bash
config firewall local-in-policy

edit 1

set interface "port3"

set srcaddr "trusted-admin"

set dstaddr "all"

set schedule "always"

set service "HTTPS"

set action deny

next

end
```

Validation:

* [ ] Interface is correct
* [ ] Source object exists
* [ ] Service matches traffic
* [ ] Policy order verified
* [ ] Logging enabled

# 4. Administrative Access vs Local-In Policy

## Administrative Access

Configuration:

```bash
config system interface
```

Controls:

```
Can HTTPS run on this interface?

Can SSH access this interface?

Can Ping reach this interface?
```

---

## Local-In Policy

Controls:

```
Who can access?

From where?

Which service?

Allow or Deny?
```

---

# Security Memory Rule 🧠

```
Administrative Access

=
Enable FortiGate Service



Local-In Policy

=
Control Users Accessing That Service
```

---

# Comparison Table

| Feature               | Purpose                  |
| --------------------- | ------------------------ |
| Administrative Access | Enable FortiGate service |
| Local-In Policy       | Granular access control  |
| Firewall Policy       | Control transit traffic  |

# 7. TTL Policy Checklist

## Purpose

TTL Policy filters packets based on:

```
IP TTL Value
```

Configuration:

```bash
config firewall ttl-policy

edit 1

set action deny

set status enable

set srcintf "port3"

set srcaddr "all"

set service "ALL"

set ttl 64

next

end
```

---

# Important Concept

Never confuse:

```
IP TTL

!=

Session TTL
```

## IP TTL

```
Layer 3 Packet Lifetime
```

## Session TTL

```
FortiGate Session Timeout
```

---

# TTL Validation Checklist

* [ ] Capture packet TTL value
* [ ] Verify TTL policy match
* [ ] Confirm source interface
* [ ] Confirm action
* [ ] Perform controlled testing

Example:

```bash
hping3 \
-c 10 \
-d 120 \
-S \
-p 443 \
--ttl 64 \
192.168.101.1
```
