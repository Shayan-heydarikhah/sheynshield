# SheynShield — Cisco Secure Knowledge Base
Acurated, hand‑written, deeply technical collection of notes covering Cisco Security, Firewalls, VPN, ISE, ESA, WSA, DMVPN, GETVPN, ASA, and advanced enterprise security architectures.

This repository is designed as a living documentation hub for network engineers, security analysts, and learners preparing for Cisco CCNP Security, NSE, and multi‑vendor security environments and certification‑level training.  

Each file represents a complete topic, including configuration logic, packet‑flow reasoning, design considerations, and operational best practices.
The goal is to provide a clean, accessible, open-source knowledge base for anyone working with Cisco Secure technologies.

🔥 Key Topics Covered

1. Cisco ASA
- Stateful firewall architecture  
- ACLs, object groups, NAT, inspection policies  
- SSL VPN, IKEv1/v2, crypto maps  
- High availability & failover  
- Security contexts (multi‑context mode)

2. Cisco Firepower / FTD
- FMC architecture & device management  
- Access Control Policies (ACP)  
- Prefiltering, SI, URL filtering, AVC  
- IPS (Snort), file & malware inspection  
- Routing (OSPF, BGP, EIGRP) on FTD  
- HA, clustering, transparent vs routed mode

3. Cisco ISE
- AAA, TACACS+, RADIUS  
- 802.1X, MAB, EAP methods  
- Posture, profiling, client provisioning  
- TrustSec, SGT, SXP  
- BYOD workflows  
- AD integration & certificate-based auth

4. Cisco ESA
- SMTP flow, HAT/RAT tables  
- Anti-spam, anti-virus, AMP  
- Outbreak filters  
- Message filters & content filters  
- Mail routing, MX records, TLS  
- Troubleshooting (tail logs, trace)

5. Cisco WSA
- Proxy modes (explicit, transparent)  
- WCCP redirection  
- URL filtering, AVC, DLP  
- HTTPS decryption (MITM)  
- AMP, ThreadGrid  
- Access policies & identification profiles

6. VPN Technologies
- IPSec fundamentals (Phase 1/2)  
- IKEv1 / IKEv2  
- SVTI tunnels  
- DMVPN (NHRP, mGRE, shortcuts)  
- GETVPN (GDOI, KS/GM roles)
